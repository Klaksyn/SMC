# Справка по командам

В данном документе описаны все доступные команды консоли.

---

# CMD

Запуск командной строки Windows.

## Синтаксис

```text
cmd
```

Открыть командную строку Windows.

```text
cmd <команда>
```

Выполнить команду через CMD.

---

# Дата и время

Показать текущую дату.

```text
date
```

Показать текущее время.

```text
time
```

---

# Работа с путями

Команды для работы с текущей директорией.

## Смена директории

```text
cd <директория>
```

Перейти в указанную директорию.

```text
cd !$
```

Перейти в последнюю открытую директорию.

```text
cd -p <номер>
```

Перейти в директорию по её номеру из списка.

## Текущая директория

```text
pwd
```

Показать текущую директорию.

## Отображение пути

```text
path --show
path -s
```

Показать текущий путь.

```text
path --hide
path -h
```

Скрыть отображение текущего пути.

---

# История команд

Показать историю команд.

```text
history
```

Поиск по истории команд.

```text
history --search
history -s
```

или

```text
history --history_search
history -h-s
```

Сохранить историю команд в текстовый файл.

```text
history --save
history -sv
```

---

# Очистка консоли

Очистить экран консоли.

```text
clear
```

или

```text
cls
```

# Пользовательские команды

## Создание команды

```text
mkcommand <имя> <действие>
```

или

```text
mkcmd <имя> <действие>
```

Создать пользовательскую команду.

---

## Переименование

```text
change-command <старая_команда> <новая_команда>
```

или

```text
chcmd <старая_команда> <новая_команда>
```

Изменить имя существующей команды.

---

## Изменение действия

```text
change-action <команда> <новое_действие>
```

или

```text
chact <команда> <новое_действие>
```

Изменить действие, выполняемое командой.

---

## Удаление

```text
del-command <команда>
```

или

```text
delcmd <команда>
```

Удалить пользовательскую команду.

---

## Выполнение

```text
run-command <команда>
```

или

```text
rnc <команда>
rc <команда>
rn <команда>
```

Выполнить пользовательскую команду.

---

# Открытие

Открыть текущую директорию в Проводнике Windows.

```text
explorer
explr
exp
openf
```

Открыть указанную директорию.

```text
explorer <путь>
explr <путь>
exp <путь>
openf <путь>
```

Запустить файл.

```text
run <путь_к_файлу>
```

Пример:

```text
run D:\t.txt
```

---

# Файлы и директории

## Создание файла

```text
touch <имя_файла>
```

Пример:

```text
touch notes.txt
```

---

## Создание директории

```text
mkdir <имя_директории>
```

Пример:

```text
mkdir Projects
```

---

## Изменение названия

```text
ren <старое имя> <новое имя>
rnm <старое имя> <новое имя>
rename <старое имя> <новое имя>
```

Изменить файл или папку.
Вы также можете указать полные пути.

---

## Удаление

```text
del <путь>
delete <путь>
remove <путь>
rmv <путь>
```

Удалить файл или директорию.

---

## Копирование

```text
copy <источник> <назначение>
```

или

```text
cp <источник> <назначение>
```

Скопировать файл или директорию.

Если указан только путь назначения, текущая директория используется как источник.

Пример:

```text
cp D:\Backup
```

---

## Перемещение

```text
move <источник> <назначение>
```

Переместить файл или директорию.

---

# Работа с текстовыми файлами

## Чтение

```text
read <файл>
```

или

```text
cat <файл>
```

Прочитать содержимое файла.

---

## Запись

```text
echo --write <текст>
```

или

```text
echo -w <текст>
```

Записать текст в файл.

---

## Перезапись

```text
echo --rewrite <текст>
```

или

```text
echo -rw <текст>
```

Полностью заменить содержимое файла.

---

## Запись нескольких строк

```text
echoln <файл>
```

Записать несколько строк текста.

```text
echoln-rw <файл>
```

Полностью заменить содержимое файла несколькими строками.

---

# Поиск

Поиск файлов и директорий.

## Синтаксис

```text
find <параметр> <имя>
```

### Параметры

| Параметр | Описание |
|-----------|----------|
| `-g` | Искать файлы и директории по всей системе |
| `-gf` | Искать только файлы по всей системе |
| `-gd` | Искать только директории по всей системе |
| `-l` | Искать файлы и директории в текущей директории |
| `-lf` | Искать только файлы в текущей директории |
| `-ld` | Искать только директории в текущей директории |

Полные параметры:

| Параметр |
|-----------|
| `--global` |
| `--global-file` |
| `--global-directory` |
| `--local` |
| `--local-file` |
| `--local-directory` |
